# Teacher Class Management System

Système moderne de gestion des classes pour enseignants, pensé pour un usage administratif et pédagogique avec une expérience utilisateur premium.

## Stack
- PHP
- MySQLi
- HTML5
- CSS3
- JavaScript
- RTL Arabic design

## Fonctionnalités
- Authentification admin / enseignant
- Dashboard moderne avec statistiques
- Gestion des classes sans spécialité
- Mini boîte de réception / messagerie interne
- Paramètres utilisateur pour modifier les infos et le mot de passe
- Interface responsive et élégante

## Comptes de démonstration
- Admin: admin@school.com / Admin@123
- Enseignant: teacher@school.com / Teacher@123

## Installation rapide
1. Importer `database.sql` dans MySQL.
2. Configurer `config/db.php`.
3. Ouvrir `login.php` dans le navigateur.

## Notes
Le projet est conçu comme une version plus soignée et visuellement moderne de la première maquette, en gardant la logique PHP orientée projet scolaire.
